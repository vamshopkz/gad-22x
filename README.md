# ГАД 2-2 X — глобальный виртуальный мир

Открытый 3D-мир будущего: большой город (центр с небоскрёбами, деловой и жилой районы, пригород,
пляж с виллами, промзона, парки), загород — горы с тоннелем, аэропорт, вокзал, морской порт.

**Играть в браузере (iPhone, Android, компьютер):** https://vamshopkz.github.io/gad-22x/
**Android APK:** https://github.com/vamshopkz/gad-22x/releases/latest/download/GAD22X.apk

## Что есть в версии 0.1
- Создание персонажа (пол, кожа, причёска, одежда), имя.
- Город из ~690 зданий; **в каждое здание можно зайти** — у каждого типа свой интерьер и действия
  (квартиры, дома, виллы, магазины, супермаркеты, ТЦ, рестораны, кафе, автосалоны, СТО, больницы,
  пожарные части, школы, университет, библиотеки, банки, отели, офисы, небоскрёбы, заводы, склады,
  подземные парковки, заправки, спортзалы, аэропорт, вокзал, порт, центр занятости).
- Машины: 9 моделей в автосалонах, вождение, аварии, ремонт, тюнинг, покраска; трафик и пешеходы.
- Работа: 24 профессии (смены в зданиях, курьер, такси), образование (школа → университет).
- Жильё: покупка квартир/домов/вилл, сон, гардероб, мебель с выбором цвета.
- Бизнес: покупка магазинов, кафе, заводов и т.д., доход каждый игровой час, улучшения.
- Смена дня и ночи (общая для всех игроков), погода: ясно, облачно, дождь, туман; свет в окнах ночью.
- Потоковая подгрузка деталей города вокруг игрока.
- **Сетевой мультиплеер**: игроки Android, iPhone и браузера в одном мире, чат, список игроков, GPS к другу.

## Сборка
Unity 6000.3.21f1, всё строится из кода (`Assets/Scripts`).
- `./build_and_test.sh DIR` — сборка для Mac + автотест со скриншотами.
- `./release.sh 0.2 "что нового"` — APK в GitHub Releases.
- `UnityProject` → `BuildScript.BuildWebGL`, затем `./publish_web.sh` — браузерная версия на GitHub Pages.
